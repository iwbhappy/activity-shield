# Изменения

## 1.1.1

- Добавлена включённая по умолчанию функция «Скрывать изменение размера окна»: размеры окна/экрана, VisualViewport, ориентация и основные размерные JS matchMedia фиксируются на время документа; события resize/ориентации фильтруются.
- Корневые clientWidth/Height и размеры прямоугольников HTML/body фиксируются; повторные ResizeObserver-уведомления уже наблюдаемых корней подавляются. Обычные элементы сохраняют нативную геометрию и наблюдатели.
- Старые настройки/резервные копии 1.1.0 мигрируют, белый список и полностью выключенные профили сохраняются. Совместимый профиль отключает новую функцию.
- Демо показывает размеры и ориентацию. Проверены настоящее изменение размера в Chromium/Firefox и миграция настроек; полный набор и Android-прогон для этого изменения не запускались.

Ограничения: CSS, вычисленные стили и геометрия обычных элементов всё ещё раскрывают изменение косвенно. Неподдерживаемые размерные matchMedia-выражения получают постоянный false. Функция может мешать адаптивным интерфейсам; отключается отдельно для сайта. После обновления перезагрузите страницы. Публикация Firefox в Mozilla выполняется отдельно.

## 1.1.0

- Отдельные переключатели защиты для каждого домена и общие настройки. Совместимый профиль сохраняет нативное выделение для редакторов и настоящий полный экран.
- Проверка загрузки в текущей вкладке, обозначения ON/OFF/R и напоминание о перезагрузке при расхождении настроек.
- Общая пауза без удаления белого списка и профилей. Существующие исключения мигрируют автоматически.
- Экспорт и импорт настроек JSON с проверкой формата, предварительным просмотром и явным применением.
- Локальный диагностический отчёт без адресов, доменов, текста страницы и буфера обмена.
- Дополнительные фильтры copy/cut, pagehide/freeze/resume, возврата из кэша и ухода указателя без связанного элемента. По умолчанию выключены; вставка и предупреждения о несохранённых изменениях сохраняются.
- Автоматические браузерные проверки и сборка релизов по тегу в GitHub Actions. Публикация в Mozilla выполняется отдельно.

Статус подтверждает загрузку модулей и выборочную проверку API, а не полную защиту от слежки. Профили действуют на точный домен; белый список — также на поддомены. Изменения требуют перезагрузки открытых страниц.

Первый запуск CI заблокирован GitHub до выполнения шагов из-за ограничения аккаунта по оплате. Для 1.1.0 используются локально проверенные сборки. После устранения ограничения workflow сможет проверять изменения и выпускать последующие релизы. Подробности и ссылка на запуск — в [GITHUB.md](https://github.com/iwbhappy/activity-shield/blob/main/GITHUB.md).

Настольные проверки прошли. Android-проверка частичная: основные сценарии завершились, но полный тест отменён по таймауту; повторению помешали отладчик и отключение эмулятора. Новые мобильные настройки и опциональные фильтры требуют отдельной проверки. Подробности — в [ANDROID.md](https://github.com/iwbhappy/activity-shield/blob/main/ANDROID.md#версия-110).
