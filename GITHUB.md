# GitHub и распространение сборки Chromium

Текущая версия проекта — 1.0.4. Репозиторий исходников: [iwbhappy/activity-shield](https://github.com/iwbhappy/activity-shield). Готовые файлы: [GitHub Releases](https://github.com/iwbhappy/activity-shield/releases). Публикация в Chrome Web Store пока не выполнена. Исходники, архивы для скачивания и магазин расширений выполняют разные задачи.

**Firefox:** [установка из Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/activity-shield-%D1%83%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82/). В GitHub-релизах распространяется Chromium ZIP; постоянную Firefox-установку удобнее получать из каталога Mozilla.

## Установка по ссылке с автоматическими обновлениями

Основной канал для обычного настольного Chrome — **Chrome Web Store**. Brave также устанавливает расширения из этого магазина; поддержка и ограничения остальных Chromium-браузеров проверяются отдельно. Для браузеров нужны MV3 и используемые API Chromium 119+. Обычный Chrome Android расширения не устанавливает.

1. Зарегистрируйте аккаунт разработчика Chrome Web Store. У Google предусмотрен однократный регистрационный платёж; текущие условия показываются при регистрации.
2. Откройте [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole/) и выберите **Add new item**.
3. Загрузите **`dist/activity-shield-chromium.zip`**. В нём manifest.json находится в корне. Firefox XPI и полный submission.zip для этой формы не подходят.
4. Заполните описание, назначение, обоснование разрешений и сведения о данных. Потребуются также графические материалы карточки (иконка, скриншоты и другие обязательные поля магазина). Они не заменяются архивом кода; окончательные требования покажет форма магазина. В текущем пакете отдельные иконки расширения ещё не добавлены.
5. Назначение: ограничение прямых JavaScript-сигналов активности страницы с управляемыми исключениями доменов. `storage` нужен для локального белого списка, `scripting` — для ранней регистрации упакованного shield.js, HTTP(S)-доступ — для применения к выбранным страницам. Удалённый код, аналитика и передача пользовательских данных отсутствуют.
6. Отправьте пакет на проверку. После публикации передавайте пользователям ссылку на карточку магазина.
7. Следующие версии загружайте в **ту же карточку** с большим номером версии. Обновления выполняет браузер. Ранее загруженные распакованные копии автоматически не превращаются в установки из магазина: для перехода установите версию из карточки, оставив включённым один вариант.

Для отдельного канала Edge можно опубликовать Chromium ZIP в [Microsoft Edge Add-ons](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension) через Partner Center. Это отдельная карточка, проверка и канал обновлений. Публикация в Mozilla обновляет Firefox.

## Исходники на GitHub

Подготовлен **`dist/activity-shield-source.zip`** — архив исходников, тестов, демо и документации. Он не содержит node_modules, эмулятор, тестовые профили или собранные dist-пакеты.

Простой способ через сайт GitHub:

1. Создайте репозиторий, например `activity-shield`. Для общего доступа выберите Public.
2. Распакуйте `activity-shield-source.zip` в отдельную папку.
3. В репозитории выберите **Add file → Upload files** (для пустого репозитория — ссылку загрузки существующих файлов).
4. Перетащите **распакованное содержимое**, сохранив папки. Сам ZIP не разворачивается GitHub в дерево исходников.
5. Сохраните загрузку кнопкой **Commit changes**. README.md отобразится на главной странице.

Исходники также можно отправить обычным Git. В проекте .gitignore исключает dist/, node_modules/, .android-test/, test-results/, web-ext-artifacts/, локальные .env и файлы ключей. Изменять лицензию проекта или создавать репозиторий от вашего имени подготовка архива не выполняет.

После скачивания исходников сборка выполняется в корне:

```powershell
npm ci
npm run pack
```

Нужен Node.js 22+. В dist/ появятся архивы для разных браузеров и комплект для сдачи.

## Готовые файлы в GitHub Releases

1. Откройте **Releases → Draft a new release**.
2. Создайте тег `v1.0.4`, укажите название релиза и описание изменений.
3. Прикрепите `dist/activity-shield-chromium.zip`. При необходимости добавьте комплект для сдачи и исходники.
4. Для обычного Firefox можно приложить **подписанный Mozilla XPI**, скачанный после одобрения. Локальный файл с `unsigned` в имени для постоянной установки обычного Firefox не подходит.
5. Опубликуйте релиз. Пользователи получат постоянную страницу скачивания файлов.

GitHub автоматически предлагает также архив исходников тега. Этот архив репозитория не является готовым установочным ZIP расширения: пользователь должен либо собрать проект, либо скачать прикреплённый Chromium ZIP.

### Ручная установка Chromium ZIP из Releases

1. Скачать `activity-shield-chromium.zip` и распаковать его в постоянную папку.
2. Открыть `chrome://extensions` (в Edge — `edge://extensions`).
3. Включить режим разработчика → «Загрузить распакованное расширение».
4. Выбрать папку с manifest.json.
5. Открыть меню Activity Shield, дождаться загрузки белого списка и обновить проверяемые страницы.

Эта установка подходит для тестов. GitHub Releases сам по себе не включает автоматическую установку или обновление расширения. Для новых версий распакованной установки потребуется заменить файлы, обновить расширение в менеджере и перезагрузить сайты. Для обычного Chrome на Windows/macOS собственный update_url на GitHub не заменяет магазин; отдельные механизмы самостоятельного распространения доступны в управляемых средах.
