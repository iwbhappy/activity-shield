# Activity Shield

Учебное расширение приватности для Chromium и Firefox. Ограничивает прямые сведения об активности вкладки, выделении текста и вызове контекстного меню, доступные скриптам сайтов. Версия исходников **1.1.0**: профили сайтов, общая пауза, перенос настроек, локальная диагностика и дополнительные фильтры событий. [История изменений](CHANGELOG.md).

## Firefox — установка из Mozilla Add-ons

**[Установить Activity Shield для Firefox](https://addons.mozilla.org/ru/firefox/addon/activity-shield-%D1%83%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82/)**

Откройте страницу в Firefox и нажмите кнопку установки. На странице Mozilla указана текущая опубликованная версия и совместимость с устройством. Для установок из каталога обновления доставляет Firefox, если автоматические обновления включены.

Проект рассчитан на Firefox 128+ на компьютере и Firefox Android 142+. После установки разрешите доступ к нужным сайтам, откройте меню расширения и перезагрузите уже открытые страницы. Полезные сведения о мобильной версии — в [ANDROID.md](ANDROID.md).

## Chromium — скачать и установить вручную

**[Скачать сборку Chromium из последнего релиза](https://github.com/iwbhappy/activity-shield/releases/latest/download/activity-shield-chromium.zip)** · [Все релизы](https://github.com/iwbhappy/activity-shield/releases)

Сборка предназначена для настольных браузеров на Chromium 119+ с поддержкой расширений Manifest V3 и используемых API. Автоматические проверки выполнялись в Chromium; работа в каждом производном браузере отдельно не гарантируется. Обычный Google Chrome на Android расширения не устанавливает.

1. Скачайте `activity-shield-chromium.zip` и распакуйте в постоянную папку.
2. Откройте менеджер расширений: `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите режим разработчика и нажмите **«Загрузить распакованное расширение»**.
4. Выберите распакованную папку, в которой находится `manifest.json`.
5. Разрешите доступ к нужным сайтам. Откройте меню Activity Shield, дождитесь загрузки белого списка и обновите страницы.

При ручной установке папку с файлами необходимо сохранять. Для обновления скачайте новую сборку, замените файлы, нажмите обновление расширения в менеджере и перезагрузите сайты. GitHub Releases не включает автоматическую доставку обновлений в браузер.

Публикация в Chrome Web Store пока не выполнена. Способы распространения описаны в [GITHUB.md](GITHUB.md), публикация Firefox — в [PUBLISHING.md](PUBLISHING.md).

## Возможности

| Проверка или действие сайта | При включённой защите |
| --- | --- |
| `document.hidden`, `document.visibilityState` | `false`, `visible` |
| `document.hasFocus()` | `true` |
| События видимости и потери/возврата фокуса при уходе из браузера | Фильтруются |
| Чтение выделения документа и текстовых полей | Синтетическое пустое выделение |
| События выделения, ПКМ, клавиши меню и Shift+F10 | Фильтруются |
| `requestFullscreen()` | Синтетический успех; браузер остаётся в обычном окне |
| Обычные клики и переходы между полями | Сохраняются |
| `copy` / `cut` | Дополнительный фильтр, изначально выключен; стандартное копирование не отменяется |
| `pagehide`, `freeze`, `resume`, восстановление `pageshow` | Дополнительный фильтр; первый `pageshow` и `beforeunload` сохраняются |
| Уход указателя без связанного элемента | Дополнительный фильтр `mouseout/leave`, `pointerout/leave` с `relatedTarget === null` |

Расширение не отменяет стандартное выделение текста и контекстное меню браузера. Редакторы, которым нужен доступ к настоящему выделению, могут работать неправильно: отключите скрытие выделения для этого домена или добавьте его в белый список.

## Профили, пауза и статус

1. Откройте меню расширения на нужном сайте → **«Настройки защиты»**.
2. Выберите **«Только к текущему домену»** или общие настройки. Включите нужные функции и нажмите **«Сохранить защиту»**.
3. Перезагрузите страницу. Профиль действует на точное имя домена, на всех его портах и путях. Поддомены настраиваются отдельно. Вложенные фреймы используют настройки собственного URL; `about:blank`/`srcdoc` с подходящим инициатором обрабатываются браузером по origin fallback.

**Совместимый профиль** оставляет защиту видимости/фокуса и ПКМ, возвращая нативное выделение и полный экран. **«Все фильтры»** включает также три дополнительные защиты. Обе кнопки только выбирают переключатели: для применения нажмите сохранение. Белый список отключает всё и имеет приоритет над профилем.

**«Пауза на всех сайтах»** сохраняет список и профили. Пауза остаётся после перезапуска браузера до возобновления. Уже открытые страницы нужно перезагрузить: ранее изменённые API невозможно безопасно вернуть одним снятием регистрации.

Статус проверяет загруженные модули в изолированном мире основной страницы и выборочно — наличие подмены основных API. Значки: **ON** — выбранные модули загружены, **OFF** — защита выключена, **R** — требуется обновить страницу, **?** — нет доступа. Интерфейс Android может не показывать значок. На служебных страницах статус недоступен. Это не проверка всех обработчиков и не доказательство полной защиты от слежки или вмешательства самой страницы.

## Перенос настроек и диагностика

В меню **«Перенос настроек»** можно скачать JSON и импортировать его на другом устройстве. Импорт проверяет формат и размер до 1 МБ, показывает количество правил и заменяет настройки только после нажатия **«Заменить настройки из файла»**. Неверный файл не меняет настройки. Резервная копия содержит ваши домены: передавайте её только тем, кому хотите их раскрыть. Автоматической синхронизации нет.

В **«Диагностика»** можно сформировать, просмотреть и скачать отдельный JSON. В нём только версии браузера/расширения, переключатели, количества правил и состояние проверки. Адреса, домены, текст страниц, сообщения и буфер обмена в отчёт не входят. Отчёт никуда не отправляется автоматически.

## Белый список

Откройте меню расширения и нажмите **«Отключить защиту на этом домене»** либо введите домен или URL вручную. Правило действует на домен и его поддомены, на HTTP и HTTPS. Путь и порт введённого URL не ограничивают правило.

**WhatsApp Web (`web.whatsapp.com`) добавлен в исключения по умолчанию.** Исключение можно удалить. Настройки хранятся локально в текущем профиле браузера и не синхронизируются между устройствами.

После изменения списка обязательно перезагрузите страницу. Уже внесённые изменения JavaScript-прототипов сохраняются до перезагрузки документа. Правила применяются к URL каждого фрейма отдельно; для встроенного содержимого другого домена может понадобиться отдельное исключение.

## Сборка из исходников

Нужен Node.js 22+.

```powershell
git clone https://github.com/iwbhappy/activity-shield.git
cd activity-shield
npm ci
npm run pack
```

Готовые папки и архивы появятся в `dist/`:

- `dist/chromium/`, `dist/activity-shield-chromium.zip` — настольная Chromium-сборка.
- `dist/firefox/`, `dist/activity-shield-firefox.zip` — исходная Firefox-сборка без подписи Mozilla.
- `dist/firefox-android/` — отдельная разработческая Android-сборка с другим ID.
- `dist/activity-shield-source.zip` — исходники, тесты и документация.
- `dist/submission.zip` — полный учебный комплект со сборками и пояснительной запиской.

Для обычной установки Firefox используйте ссылку Mozilla выше: самостоятельно собранные пакеты не получают подпись автоматически. Для разработки Firefox можно временно загрузить `dist/firefox/manifest.json` через `about:debugging#/runtime/this-firefox`.

## Проверочная страница

```powershell
npm run demo
```

Откройте **http://127.0.0.1:8080/**. Сервер доступен только локально.

Сначала отключите расширение и обновите страницу, затем повторите проверку с включённым расширением после перезагрузки. Сравните выделение текста, ПКМ, переключение вкладок/приложений и запрос полного экрана. Страница использует обычные браузерные API и не включает защиту сама.

Для проверки белого списка добавьте домен демо в исключения, перезагрузите страницу и убедитесь, что она снова получает нативные значения. После удаления исключения и перезагрузки защита вернётся.

## Автоматические проверки

```powershell
npx playwright install chromium
npm test
npm run android:lint
npm run pack
npm run release:check
```

Для Firefox-проверок нужен установленный Firefox; Selenium Manager подбирает geckodriver. Набор проверяет настоящее установленное расширение и контрольный режим без него: API, реальные клики, ввод, фреймы, полный экран, белый список, редактор с Selection API и перезапуск Chromium. Также проверяются независимые профили, статус до/после перезагрузки, пауза, фильтры событий, экспорт/импорт через интерфейс и миграция старого белого списка. Дополнительные обработчики проверяются тестовыми событиями; это не имитация всех нативных сценариев ОС.

GitHub Actions запускает эти проверки на Windows при изменении main и pull request. Тег `v<версия>` после успешных проверок создаёт GitHub Release с архивами и SHA-256. [Порядок выпуска](GITHUB.md). Подпись и публикация Firefox в Mozilla выполняются отдельно.

Android-проверка запускается отдельно на подготовленном тестовом устройстве или эмуляторе — см. [ANDROID.md](ANDROID.md). Сохранённые результаты относятся к указанным в них версиям и средам, а не ко всем браузерам и телефонам.

## Приватность и ограничения

Код расширения не отправляет данные на серверы, не содержит аналитики и не загружает удалённый JavaScript. Настройки хранятся в `storage.local`; при обновлении сохраняется существующий белый список. `scripting` запускает выбранные упакованные модули при `document_start` и проверяет статус; доступ к HTTP(S)-страницам нужен для применения защиты, `activeTab` — для работы с текущей вкладкой после открытия меню. Чтение истории и доступ к буферу обмена не запрашиваются.

Это защита от перечисленных прямых API и событий. Она не гарантирует отсутствие слежки или неотличимость от активного пользователя:

- Сайт может обнаружить подмену, изменить прототипы или получить чистые API из другого контекста.
- Таймеры, `requestAnimationFrame`, заморозка и выгрузка вкладок остаются под управлением браузера.
- Обычные движения мыши, касания, ввод, CSS-состояния и другие косвенные сигналы доступны сайту.
- Размеры окна, CSS `:fullscreen` и браузерный F11 не подменяются. Синтетические события имеют `isTrusted: false`.
- IP-адрес, cookies, fingerprinting, камера, микрофон и сетевой трафик этим расширением не скрываются.
- Защита не работает на внутренних страницах браузера и в других запрещённых браузером местах. Для приватных окон требуется отдельное разрешение.

Полноэкранное видео и игры с защитой также могут оставаться в окне. Чтобы вернуть нативное поведение, отключите синтетический полный экран в профиле домена или добавьте его в белый список и перезагрузите страницу. Фильтр жизненного цикла скрывает события, но не предотвращает фактическую заморозку/выгрузку; фильтр ухода указателя не скрывает обычные движения мыши. Фильтр copy/cut не запрещает Clipboard API и может мешать пользовательскому формату копирования на сайтах.

- `scripts/` — сборка, упаковка, локальный сервер и запуск Android-сборки.

- `android/` — сохранённые результаты мобильных прогонов.

- [PUBLISHING.md](PUBLISHING.md) — публикация и обновления Firefox.
