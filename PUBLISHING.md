# Публикация и автоматические обновления Firefox

**Страница установки Firefox:** [Activity Shield — учебный проект на Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/activity-shield-%D1%83%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82/).

Для публичного каталога Mozilla (AMO) подготовлена версия **1.0.4**. Пользователь уже загрузил 1.0.3; новый номер нужен для повторной отправки в публичный канал, поскольку AMO не принимает повторный номер версии даже в другом канале. Код защиты и настроек тот же, что в проверенной 1.0.3; изменены номер версии и подпись в меню. Публичная публикация из аккаунта ещё не подтверждена.

## Существующие установки

Подписанные 1.0.1/1.0.2 из проекта не содержат `update_url`. По правилам Mozilla такие самораспространяемые дополнения проверяют AMO на наличие **публичной** новой версии с тем же ID. Простая подпись следующего unlisted XPI не включает доставку обновлений.

1. Откройте существующее дополнение «Activity Shield — учебный проект» в центре разработчиков Mozilla. Создавать отдельное дополнение с другим ID не требуется.
2. Нажмите «Загрузить новую версию». **До выбора файла**, вверху первого экрана, найдите блок размещения версии (**Where to Host Version**) и нажмите ссылку **«Изменить» / Change** рядом с текущим способом распространения. Выберите **listed / On this site / На этом сайте**, нажмите «Продолжить». Затем загрузите `dist/activity-shield-firefox.zip` версии **1.0.4**. Ссылка выбора канала присутствует в [исходном шаблоне AMO](https://github.com/mozilla/addons-server/blob/master/src/olympia/devhub/templates/devhub/addons/submit/upload.html).
3. Заполните карточку дополнения и выберите совместимость Firefox и Firefox Android. В архиве уже указаны Firefox 128+ и Firefox Android 142+.
4. Если запрошены исходники, приложите `dist/submission.zip`. Инструкции воспроизведения: Node.js 22+, `npm ci`, `npm run build`; код не минифицирован. `npm run pack` дополнительно создаёт архивы.
5. После одобрения убедитесь, что версия 1.0.4 **опубликована в каталоге**, а не только подписана для скачивания разработчиком.
6. На устройствах оставьте автоматические обновления Firefox включёнными. На компьютере для проверки откройте `about:addons`, меню шестерёнки → поиск обновлений. Обновления проверяются периодически, а не мгновенно после загрузки версии в аккаунт.
7. После обновления проверьте номер 1.0.4 в меню Activity Shield, перезагрузите открытые сайты. WhatsApp Web должен оказаться в белом списке по умолчанию.

Файлы в `dist/` не подписаны. Публикация в AMO и её одобрение не выполняются командой сборки проекта. Код расширения не скачивает и не выполняет JavaScript с сервера: обновляется подписанный пакет средствами Firefox.

Общий ID настольной/совместимой Android-сборки: `activity-shield@antiprotection.local`. Отдельная экспериментальная Android-сборка имеет ID `activity-shield-android@antiprotection.local`. Её установки не получат пакет с другим ID: для неё нужен собственный публичный канал либо однократный переход на общую сборку. Временные установки через USB и `about:debugging` не следует использовать для проверки постоянных обновлений.

## Готовый текст карточки

**Краткое описание:** Учебное расширение приватности: скрывает прямые сигналы активности страницы и выделения текста, поддерживает исключения для сайтов.

**Полное описание:**

Activity Shield изменяет JavaScript API видимости и фокуса страницы, скрывает чтение выделения и события контекстного меню. Запрос полного экрана может завершаться синтетически: сайт получает состояние полного экрана, а браузер остаётся в обычном окне.

Добавляйте несовместимые сайты в белый список через меню расширения. На указанных доменах и их поддоменах защитный скрипт не запускается. WhatsApp Web включён в исключения по умолчанию. После изменения настроек перезагрузите сайт.

Это учебный инструмент с ограниченной моделью защиты. Он не скрывает IP, cookies, сетевой трафик или все косвенные признаки активности. Подмена API может нарушать редакторы, игры и полноэкранное видео. Синтетические события отличимы от настоящих.

**Данные и приватность:** Расширение не собирает и не передаёт персональные данные, переписку или историю посещений. Белый список хранится в локальном хранилище расширения на устройстве. Встроенной синхронизации настроек между устройствами нет.

**Примечания к версии 1.0.3:** Добавлен редактируемый белый список и кнопка отключения защиты для домена. WhatsApp Web исключён по умолчанию. Исправлена совместимость с редакторами через отключение подмены на выбранных доменах. Сохранены прежние функции приватности и синтетического полного экрана.

**Примечания к версии 1.0.4:** Пакет подготовлен для публичного канала AMO и автоматических обновлений. Функциональность версии 1.0.3 сохранена; новый номер нужен после уже выполненной загрузки 1.0.3. Публикация в каталоге завершается отдельно в центре разработчиков Mozilla.

**Примечания проверяющим:** `storage` используется только для локального белого списка. `scripting` регистрирует упакованный `shield.js` в MAIN при `document_start`, с `excludeMatches` из списка. Chromium использует service worker, Firefox — модульную event page. Сетевых загрузок кода нет. Для независимой демонстрации выполните `npm ci` и `npm run demo`, откройте `http://127.0.0.1:8080/`.

## Chromium

Пошаговая публикация Chrome Web Store, размещение исходников и готовых архивов на GitHub — в [GITHUB.md](GITHUB.md). Для исходников подготовлен `dist/activity-shield-source.zip`, для магазина — `dist/activity-shield-chromium.zip`.

Публикация в Mozilla обновляет только Firefox. Распакованная сборка Chromium не получает обновления из AMO. Для автоматического распространения в Chrome/Edge нужен соответствующий магазин расширений и сохранение ID пакета; это отдельная публикация.
